CleanCare

A single CMS star rating hides a lot of real variation between healthcare facilities. I built CleanCare to join public CMS data on nursing homes, hospitals, and ambulatory surgical centers into one PostgreSQL database, so anyone can look past the star rating and see real numbers on staffing, ownership, and outcomes.

  • Built three fully independent pipelines, one per facility type, each with its own schema, data loader, query layer, web pages, and chat tools.
  • Exposed the data through a 19 tool MCP server, a full web dashboard with fuzzy search, near me search, guided search, and side by side facility comparison, and an in site AI chat assistant.
  • Powered the chat assistant with a Groq hosted Llama 3.3 70B model, available across all three facility types.
  • Backed the entire platform with 128 automated pytest tests run against the real database, with CI via GitHub Actions on every push.
Python PostgreSQL Docker pandas FastAPI Jinja2 MCP Groq GitHub pytest

Academic Paper Recommendation System

Researchers waste hours searching for relevant papers. I built a hybrid recommendation system that blends three different ranking signals across 23.4 million research papers and 278.6 million citation links to surface what actually matters.

  • Combined semantic similarity from BERT, citation based graph structure from Node2Vec, and keyword overlap from BM25 into one weighted relevance score.
  • Built the full pipeline on AWS EC2 and S3 to handle a dataset far too large to process on a laptop.
  • Added a Gemini powered learning path feature that organizes recommended papers by difficulty level, from foundational to advanced.
  • Applied product quantization to cut the FAISS index size by 97 percent, bringing around 40GB of model and index artifacts down to a fraction of that in S3.

Similar Image Finder

Traditional image search often misses semantic similarity, matching on color or shape instead of what an image is actually about. I built a tool that finds visually and semantically similar photos using OpenAI's CLIP model, letting users upload an image or paste a URL and instantly get back related results from a large photo collection.

  • Built a Streamlit web app where users upload an image or paste an image URL to search for visually similar photos.

  • Deployed the app live on Streamlit, returning the top 6 most visually similar images for any uploaded photo or image link.
